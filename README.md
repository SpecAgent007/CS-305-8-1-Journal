# CS-305-8-1-Journal

For this project, my client was Artemis Financial, a financial consulting company that needed help securing its web application to protect sensitive customer data and meet financial regulations. The original starter code was running over unencrypted HTTP and had no way to verify data integrity, so the company needed me to add SSL/TLS encryption, generate a self-signed certificate, and implement a cryptographic hash checksum. When finding and fixing these vulnerabilities, I did a good job isolating the security issues and using trusted, built in libraries rather than trying to write custom encryption from scratch. Coding securely is important because a single data breach in the financial industry can expose private customer records, ruin a company’s reputation, and lead to heavy legal fines. Building security in from the start protects the company's finances and maintains client trust. The most challenging part of the vulnerability assessment was getting the OWASP Dependency Check plugin in Maven to run properly after older database feeds and analyzer settings caused build errors, but working through those errors was really helpful for understanding how third party libraries are scanned for CVEs.   To increase layers of security, I added SHA-256 checksum hashing inside the /hash controller endpoint to verify data integrity, and I generated a 2048-bit RSA keystore using Java keytool to force the server onto HTTPS over port 8443. In the future, I will continue using static analysis tools alongside NIST and OWASP guidelines to weigh the severity of CVEs and pick the right mitigation techniques. To make sure the refactored application was both functional and secure, I manually reviewed the code for syntax or logic errors, started the Spring Boot server in Eclipse, and tested https://localhost:8443/hash in my browser to verify the checksum output. After refactoring, I re ran the OWASP Dependency-Check static scanner and checked the HTML report to confirm my changes did not introduce any new vulnerabilities. Tools and practices from this project, like Java keytool, MessageDigest, Maven dependency scanning, will definitely be useful in the future and software engineering tasks. For future employers, I can showcase the refactored Spring Boot codebase and my Practices for Secure Software Report to demonstrate that I know how to implement HTTPS, write SHA-256 integrity checks, and run static security audits.
